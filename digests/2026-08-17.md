**OrchestraBench + Layer-Isolated together provide a two-level answer to the Horizon Gap's model-vs-harness open problem.** The Horizon Gap (Aug 16) identified as an open problem: how to decompose what the model contributes to long-horizon performance from what the scaffolding/harness adds. OrchestraBench answers at the planning/execution boundary — hold the scaffold fixed, vary the planner — and finds that most frontier-model performance differences are system-level (p≈0.821 near-equality in the controlled planner bakeoff). Layer-Isolated Evaluation answers at the scaffold-component level — which scaffold layer fails — showing that aggregate task success masks per-layer regressions by 25–91 pp. Together: OrchestraBench separates model from scaffold; Layer-Isolated separates scaffold layers from each other. The aggregate-masking finding in both papers independently validates the Horizon Gap's core critique of outcome-only evaluation for long-horizon agents.

**Atomic Skills Prerequisite formalizes the boundary condition for PASS@(k,T) capability expansion.** PASS@(k,T) (Aug 16) showed RL genuinely expands capability boundaries for compositional tool-use tasks but only improves reliability for simpler ones, without explaining why. Atomic Skills Prerequisite fills this gap: RL expands capability only when atomic component skills are already mastered (SFT prerequisite); otherwise RL only amplifies seen patterns without synthesizing novel compositions. This means the vault's training-mechanism papers (PAIR, CSO, RSPO, SRGPO, Temporal GRPO, Skill-Entropy RL) should be evaluated not just on aggregate accuracy gains but on whether the base model already had the relevant atomic skills — the synthesis benefit is conditional on this prerequisite. Skill Entropy (Aug 16) measures this prerequisite implicitly: low per-skill entropy (stable atomic skills) is the condition under which Skill-Entropy RL's compositional gains materialize.

**REVERSE introduces offline search cache as a stability mechanism for retrieval-based RL, paralleling ToolRL-DR's domain randomization approach to environmental stochasticity.** ToolRL-DR (Aug 16) addressed deployment stochasticity (POMDP transition perturbations) via domain-randomized RL on non-transition perturbations, achieving retry-policy transfer. REVERSE addresses training-time stochasticity (noisy search results vary across RL rollouts) by caching search results offline, making retrieval observations deterministic for credit assignment. Both identify environmental stochasticity as the core obstacle to dense process supervision and propose a stability mechanism: domain randomization (ToolRL-DR) vs. cache-based determinism (REVERSE). The visual grounding process reward also provides an application-specific instantiation of Gap #7 (visual faithfulness as VLM RL training signal): grounding reward is a verifiable visual faithfulness proxy in a geo-localization context.

**ProFact extends process-aware agentic RL to structured NLP pipelines, completing a five-architecture taxonomy for process reward sources.** The vault's process reward architectures: PAIR (internal LLM hidden-state probe), CSO (critical step DPO with reachability filter), RSPO (reward-swap: process for sampling, outcome for gradient), SRGPO (step-group relative advantage), SeekJudge (4-role specialized multi-agent). ProFact adds a sixth architecture: unified policy with stage-indexed process rewards for a multi-stage sequential pipeline. ProFact is structurally the simplest — one policy, four reward stages — and the most directly applicable to NLP task pipelines not requiring specialized verifiers.
