# SPyCE: Skill-Policy Co-evolution for Multimodal Agents

## Summary

SPyCE distills multimodal agent trajectories into a hierarchical skill library—execution skills for local visual operations and workflow skills for high-level tool orchestration—that co-evolves with the policy during RL training. The policy conditions on retrieved skills to guide rollouts, while the skill library evolves using valuable rollouts generated by the policy, creating a closed training loop where improved policies yield better skills and evolving skills provide stronger rollout priors. Across eight multimodal benchmarks, SPyCE consistently outperforms both RL-based and memory-based baselines, with ablations confirming both hierarchical skill design and co-evolution are critical.

## Key Contributions

- Two-level skill hierarchy: execution skills (local visual operations) and workflow skills (high-level tool orchestration priors)
- Closed co-evolution loop: policy generates rollouts → good rollouts update skill library → updated skills guide future policy rollouts
- Online skill evolution during RL training (not static retrieval at test time)
- Consistent gains across eight multimodal benchmarks over RL-only and memory-only baselines

## Relevance

SPyCE extends the vault's skill lifecycle synthesis (SkillRise + Bayesian-Agent + ReSkill + UCOB) into the multimodal domain. While prior skill papers focused on text-based agentic tasks (AlfWorld, WebShop), SPyCE's hierarchical skill design explicitly handles the visual operation / tool orchestration distinction that arises when the agent processes images. The co-evolution mechanism is structurally analogous to SkillRise's cross-task credit, but integrated within a single RL training run rather than across task sequences — making SPyCE the first paper in the vault to close the skill-policy feedback loop entirely within multimodal RL training.
