## Open gaps (updated)

**Open-ended agent RL reward design**: Query 2 (open-ended + reward design + agent + LLM) returned only off-topic policy-as-public-policy results. Needs a different angle. Suggested reframe: `ti:(exploration bonus OR intrinsic reward OR self-play) AND ti:(LLM OR language model) AND ti:(open-ended OR diverse OR multi-task)` — target intrinsic motivation rather than reward design broadly.

**S²VOPD augmentation for text agents**: Query 3 returned only 1 old off-topic result. The text-agent asymmetric augmentation angle appears genuinely unstudied. De-prioritize until a related framing emerges.

**ArenaFlow skill memory vs APEx + CoSkill**: CoSkill fills the ArenaFlow gap but doesn't cite ArenaFlow. An empirical comparison between tournament-ranking reward (ArenaFlow) and joint-RL skill management (CoSkill) as approaches to open-ended agent RL is still absent.

**ReuseRL MDL framing vs CoSkill joint RL**: Both address skill reuse but from orthogonal angles — compressibility-as-objective (ReuseRL) vs jointly-learnable-skill-manager (CoSkill). A unified view has not appeared.

**MATCH within-task curriculum + HarnessBandit across-task scheduling**: Together they define a two-level curriculum space; no paper addresses both levels jointly.
