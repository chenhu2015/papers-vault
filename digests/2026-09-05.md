**SINKFLEX-RL adds a training-infrastructure axis to the agentic RL efficiency map.** Three efficiency axes established through Sep 04: HARTS (rollout tree prefix sharing, compute efficiency), GAP (dependency-graph parallelization, task-structure efficiency), SCALECUA Frontier Sampling (curriculum-aware rollout allocation, task-selection efficiency). SINKFLEX-RL adds a fourth axis: attention-kernel co-design — specifically that GRPO without a value model generates long contexts from multi-turn tool use that require sink-aware FlexAttention to remain memory-feasible. The axes are orthogonal: HARTS addresses rollout tree structure, GAP addresses task decomposition graph, Frontier Sampling addresses which tasks to roll out on, and SINKFLEX-RL addresses the attention infrastructure that makes any of these feasible at long context lengths.

**Nemotron-3 provides the largest-scale validation of the SFT-then-RL ordering established by Demystifying RL Post-Training.** The Sep 03 primer established that RL success requires the base model to already place probability on correct behaviors (base model prior finding). Nemotron-3 operationalizes this at scale: 22K problem curation + synthetic SFT traces build the prior, then RL pushes the frontier. GenCorrect's iterative generate-evaluate-refine loop confirms the LLMs-as-Jury (Sep 04) finding that the jury error floor is near zero on code/math — execution-based test cases provide a clean verifiable reward signal with no ambiguity, enabling self-refinement without a trained reward model. IOI 2026: 535.4/600, first AI above the top human (498.27).

**MSRL closes the VIG+StructReward open gap in the chart domain, leaving general VLM reasoning open.** The Sep 04 prediction that VIG composability with StructReward was an open gap is partially confirmed: MSRL demonstrates the combination works (multi-granularity reward = StructReward principle; visual structural similarity reward = VIG principle). The remaining gap: no paper applies this combination to general VLM reasoning tasks (math, science, open-ended QA) rather than structured output generation. The two-stage curriculum finding (textual first, visual second) has implications for general VLM RL: visual reward alone may not be stable without a textual grounding phase.

**Influence Is Not Authority adds a fifth failure mode to the agent faithfulness audit stack.** The four-failure-mode stack established through Sep 04: CTA (skill-attribution blindness), FACE-Eval (covert adoption of tool returns), REDAgentBench (verbalization-execution gap), CSR (causal step-necessity). Influence Is Not Authority reveals a fifth: guardrail false positives at the safety/utility boundary, where influence-based causal signals conflate legitimate high-influence tool calls with malicious injections. This failure mode operates at a different layer (the safety monitor, not the policy), suggesting that any unified training intervention for the four-failure-mode stack must also account for how training changes the causal influence profile of tool calls — otherwise, training for faithful reasoning may inadvertently increase false-positive guardrail rates.
