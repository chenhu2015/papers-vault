**LongRCA Bench + "Model or Harness?" together complete the failure attribution stack begun by OrchestraBench and Layer-Isolated Evaluation.** The vault now has a four-level attribution stack: (1) OrchestraBench (Aug 17) — aggregate model vs. scaffold performance separation; (2) Layer-Isolated Evaluation (Aug 17) — scaffold layer decomposition; (3) "Model or Harness?" These papers address the same open problem at increasing resolution: from aggregate to layer to interaction to step.

**Real-Time Detection and Repair closes Gap #24 (real-time shortcut onset detection).** Gap #24 asked whether failure onset can be detected before trajectory completion and whether this can be done cheaply. The echo-state-network monitor trains only on healthy runs, runs at ~200μs/step, and achieves AUROC 0.872 across 2,823 episodes. Crucially, the detection advantage over a memoryless baseline is a monotone function of post-onset horizon: +0.09 at ≤3 steps, +0.40 at ≥9 steps. This confirms that failure onset propagates a detectable temporal signal across subsequent steps — the exact property Gap #24 hypothesised. The deterministic verification layer (96% recall, 0 false positives, zero retraining) provides a complementary structural check. **Gap #24: CLOSED.**

**RUPA provides the UQ counterpart to the attribution papers, showing that graph-structured uncertainty propagation is necessary for long-range failure detection.** The vault's attribution papers (OrchestraBench, Layer-Isolated, LongRCA Bench, "Model or Harness?") address post-hoc root-cause localisation. RUPA addresses prospective risk quantification: how much execution risk is accumulating in real time? The finding that per-step local UQ signals miss failures originating several steps before the final answer is the UQ-side validation of the Horizon Gap's core critique of step-isolated signals.

**Explicit Language Memory for VLA introduces VQA-paradigm training as a method for preserving VLM backbone quality during long-horizon action fine-tuning.** The vault's VLM training papers (BCSD, NoPD, FP-OPD, OGLS-SD — Aug 14-15) addressed on-policy distillation and self-distillation to preserve backbone quality during RL training. This paper addresses the same problem from a different angle: hierarchical decoupling (high-level VLM for reasoning via VQA, low-level VLA for control) such that the VLM backbone is never directly fine-tuned on action prediction. The explicit language memory module converts temporal observations into a textual sequence, enabling persistent tracking without requiring the VLM to store state in its weights.
