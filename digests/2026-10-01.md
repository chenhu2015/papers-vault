## Open gaps (updated)

**Tree-credit cluster now three entries**: ASCT (inference-time, RAG) + TEMPO (training-time prefix tree) + SIPO (order-statistic correction for selection bias). SIPO directly answers the TEMPO open question about branch value inflation from selection history. The design space is now: when to build the tree (inference vs. training), how to compute branch values (attentive contrast, nonparametric TD, or corrected incumbent), and whether to correct for selection bias (SIPO's contribution). Open question: do SIPO's corrections interact with TEMPO's nonparametric prefix values, or are the two methods compositional?

**Process reward for VLM agents (HaPRL)**: First VLM-specific paper with explicit process reward design. HaPRL's finding that early-stage process supervision multiplies later outcome-based gains is directly relevant to PilotRL's three-stage curriculum: when in the curriculum should process rewards be applied? HaPRL suggests front-loading them.

**TGPO automatic PRM**: TGPO's automatic PRM (subgoal progress + redundancy + verification) is a concrete no-annotation reward design complementing CCS and cross-attention signals. All three avoid gold labels via different proxies: output reconstructability (CCS), input attention fidelity (cross-attention RL), and action consistency/progress (TGPO PRM). A unified taxonomy of no-gold-label reward proxies would clarify where each applies.

**No-gold-labels design space now three entries**: CCS (cycle consistency, output-side), cross-attention RL (attention fidelity, input-side), TGPO PRM (subgoal progress, action-side). Open question: do these proxies agree on the same high-quality trajectories, or do they select for different properties? A correlation study would clarify compositionality.
