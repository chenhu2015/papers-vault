**SkillGate + RTPO together provide a two-axis fix for the multi-turn agentic RL training failure modes the vault has accumulated.** SkillGate addresses the selection axis (which tool/skill to invoke — credit starvation prevents standard RL from learning this), while RTPO addresses the temporal axis (how to assign credit across turns — flat trajectory optimization causes context mismatch, sparse-reward credit collapse, and asynchronous drift). Every paper in the vault's agentic RL stack (Agent Lightning, LEGO-RL, OrchestraBench, LongRCA Bench) implicitly requires both of these to be solved for training to be stable and effective.

**"SFT Conflicts, RL Coexists" provides the missing theoretical foundation for the SFT→RL curriculum thread.** The Aug 17 Atomic Skills Prerequisite paper established empirically that RL synthesis requires pre-mastered atomic skills; the Aug 19 SFT generalization paper established the capability + data-quality conditions for SFT generalization. Neither paper explained *why* RL is more stable than SFT in multi-task settings. This paper provides the explanation: SFT gradient interference is norm-limited (grows with gradient magnitude), while RL gradient interference is variance-limited (bounded by the small variance from advantage normalization). GRPO's advantage normalization is the specific mechanism. This closes the theoretical gap in the SFT→RL curriculum thread.

**Co-RL extends RLAIF to the unsupervised regime for both LLMs and VLMs.** The vault's RLAIF/reward-model papers (GUPO, process reward papers) all assumed verifiable reward signals. Co-RL shows that peer-cohort reward can substitute, and that diversity in the peer cohort is the critical design variable (not size). The VLM extension is particularly important: the interest profile's RLAIF keyword is mostly represented by LLM-only papers in the vault; Co-RL fills this gap for multimodal.

**ART closes a gap in the VLA + agentic tool use intersection.** The vault's VLA papers (Explicit Language Memory, BCSD, NoPD) addressed long-horizon VLA via hierarchical decoupling and distillation. ART addresses it via post-hoc tool injection: the VLA backbone is never retrained for agentic behavior, only the tool-calling interface is added. This is complementary to the distillation approach and has a dramatically smaller data footprint.
