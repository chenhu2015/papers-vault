**SFT Conflicts, RL Coexists closes Gap #1 with a theoretical mechanism.** Gap #1 (adaptive SFT→RL interleaving) has been searched for since July 28 through multiple failed queries. SFT Conflicts, RL Coexists provides the structural explanation for why adaptive interleaving is worth pursuing: interference in SFT is norm-limited (scales with gradient magnitude, making cross-task conflicts unavoidable as the model learns stronger representations), while interference in RL is variance-limited (bounded by the gradient variance induced by advantage normalization, yielding near-orthogonal updates). This means RL is not just empirically better at multi-task learning — it is *structurally guaranteed* to produce near-orthogonal task gradients by construction. Parallel-RL exploits this by fully decoupling multi-task training. Gap #1 is now theoretically explained rather than just empirically observed.

**ADRS and PCSD (Aug 4 companion) define two approaches to within-group teacher calibration in agentic RL.** Both papers were submitted the same day and address the same core problem: how should a frozen teacher snapshot's token-level preferences be calibrated against actual rollout outcomes? ADRS uses a confidence-return correlation gate (TVA): the teacher signal at each step is modulated by how well teacher confidence predicted success within the current rollout group. PCSD (from Aug 4's search 2 results, not selected today due to cap) uses temporal persistence of teacher-advantage: tokens where the teacher maintains a consistent advantage over multiple consecutive positions get upweighted, tokens where the advantage is locally declining get attenuated. These are orthogonal calibration axes: TVA asks "does teacher confidence correlate with outcomes here?", while PCSD asks "is the teacher's advantage stable over time here?". A combined TVA × persistence gate would be a natural Gap #19.

**Skill-α RL for skill generation completes the vault's skill lifecycle map.** The lifecycle synthesis ran: SkillRise (evolution) → Bayesian-Agent (lifecycle state management) → ReSkill (version selection) → UCOB (credit-integrated retrieval) → SPyCE (co-evolution in multi-modal RL). All prior papers treat the skill library as existing and ask how to use, update, or evolve it. Skill-α is the first paper in the vault to train the *skill generator* itself with RL, using a rollback reward that ties each generative edit to downstream task execution. The rollback reward is structurally analogous to UCOB's return-to-go comparison at anchor states: both compare task execution outcomes under two conditions (original vs. modified skill) at a reference query. Skill-α closes the upstream end of the skill lifecycle: generation → (SkillRise) → (Bayesian-Agent) → (ReSkill) → (UCOB/SPyCE).

**CoKL defines the "optimal correctness gap" as a new failure mode of KL regularization.** The vault's prior KL regularization coverage has been limited to entropy gating (STARE, ERPO) and clipping strategy (A²TGPO). CoKL is the first paper to formally analyze the structure of the KL constraint itself under an imperfect reference policy. The "optimal correctness gap" — a fundamental lower bound on correctness loss when the reference policy assigns non-negligible probability to incorrect outputs — is a novel characterization that applies to all standard RLHF/RLAIF settings where the reference policy is the SFT checkpoint (which is always imperfect on the training distribution). CoKL's correctness-conditioned narrowing is also structurally connected to SFT Conflicts/RL Coexists: the near-orthogonal RL gradient structure is precisely what makes CoKL's separation meaningful — if RL gradients were norm-limited (like SFT), the correctness-conditioned constraint would not be sufficient.

**FutureBridge-OPD establishes a three-paper taxonomy of "when is teacher supervision beneficial?" in agentic RL.** Prior vault papers on agentic OPD addressed *how* to supervise (PCSD: temporal persistence weights; ADRS: confidence-return gate; Guided-OPD Aug 1: curriculum decay). FTB is the first to ask *which states* to supervise, validated by future trajectory simulation. Together, the three answer the "when" question at different granularities: token level (PCSD/ADRS), step level (Guided-OPD), and state level (FTB). The combination of state-selection (FTB) × step-curriculum (Guided-OPD) × token-calibration (PCSD or ADRS) would form a complete multi-level teacher supervision framework for agentic RL — no paper yet combines all three.
