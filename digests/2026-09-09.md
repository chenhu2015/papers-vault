**Auto-Dreamer introduces offline GRPO as the fourth structural axis for memory management in language agents.** Previous approaches to agent memory: (a) retrieval-augmented (online, prompt-based), (b) structured memory with fixed schemas, (c) online RL-trained memory. Auto-Dreamer adds (d) offline GRPO-trained consolidation — the consolidator is itself an agent trained end-to-end with downstream performance rewards, but the training data comes from completed sessions rather than online rollouts. This is the only approach that explicitly learns cross-session abstraction rather than per-session storage.

**ExecCritic and ERPO independently converge on execution-based reward as a first-class training signal.** ExecCritic: behavioral validity of generated tests (do tests distinguish correct from incorrect patches?). ERPO: probe consensus reward (do candidate programs agree on probe inputs?). Both treat execution outcomes as the primary reward signal rather than a proxy (LLM judge, format check). This convergence is structurally significant: it extends the "execution artifact as credit source" open gap (identified Sep 08) from a theoretical observation to two concrete implementations with distinct reward constructions — ExecCritic uses ground-truth-validated test qualification, ERPO uses self-consensus without ground truth.

**Co-Evolving Harnesses introduces model-harness compatibility as a new failure mode in agentic RL.** The finding that imitation of a stronger expert *on an evolved harness* causes 4-30 point regressions — while the same imitation *helps* on the unevolved harness — is a previously unreported interaction. The on-policy correction fix (meta-MLE agent rewrites only the failing turn in the weaker model's own rollout) is structurally equivalent to per-turn credit assignment via expert demonstration: the meta-agent assigns "negative credit" to the single failing turn and corrects it with expert behavior, preserving all other turns. This connects the harness evolution thread (EvoHarness-RL) to the per-turn credit assignment thread (TRIAL, RTPO).

**DMPO provides the theoretical bridge from single-turn DPO to multi-turn agentic preference optimization.** The state-action occupancy measure constraint is the minimal change needed to make the DPO objective mathematically valid for multi-turn settings. This is the formal grounding for the Agentic-DPO open gap: any attempt to apply preference optimization to multi-turn VLM agents must either use DMPO's occupancy measure formulation or an equivalent correction. The occupancy measure formulation also implies that offline preference pairs can be collected from completed trajectories without online rollouts — directly relevant to the SFT-free VLM RL gap.
