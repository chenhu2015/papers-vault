**SSOPD introduces intra-group self-distillation as the 8th mechanism in Gap #20's multi-level teacher supervision.** The vault's mechanism inventory for Gap #20 now spans: (1) state-selection (FutureBridge-OPD), (2) token-type (RP-OPSD), (3) step-curriculum (Guided-OPD), (4) token-divergence-calibration (DASH/PCSD/ADRS/OCSD), (5) counterfactual-robustness-filtering (CSCR), (6) visual-evidence-attribution (VAD), (7) counterfactual-policy-regularization (CFPO), and now (8) **intra-group self-distillation (SSOPD)**. SSOPD is the first mechanism in this list that requires no external teacher: the policy's own rollout group provides both the supervision source (correct completion) and the supervision target (wrong completion prefixes). The frontier weight (active only when both branches coexist) provides a natural analog to GRPO's group-filter: just as GRPO's all-fail filter prevents useless updates from groups with no correct answer, SSOPD's frontier weight prevents useless distillation from groups with no wrong answer.

**SOD identifies a new failure mode class for OPD in agentic RL: cascading divergence amplification.** The vault's existing failure-mode awareness for OPD: (A) CSCR's surface-concentration finding — teacher signals concentrate on surface-form tokens regardless of outcome, making step-sensitive credit unreliable; (B) the VAD/CFPO visual shortcut problem — OPD corrections from multimodal teachers contain source-mixed visual signals. SOD introduces a third class: (C) **cascading tool-call error amplification** — an erroneous tool call at step T produces an incorrect environment state, causing every subsequent student-teacher divergence to be measured against a trajectory branch that the student cannot recover from. This is unique to agentic RL because tool calls have permanent state effects that compound; it is absent in closed-form reasoning RL where each token operates on the same context. SOD's divergence-adaptive gating is a step-level analog of CSCR's surface-concentration mitigation — both reduce supervision weight where the teacher signal is unreliable.

**CANON and SoftmaxGRPO together form a direction-aware entropy-shaping pair.** SoftmaxGRPO (Aug 11) used temperature-scaled softmax normalization to control entropy during GRPO training — a direction-prescribed intervention (higher temperature → higher entropy). CANON's entropy application uses inter-group comparison to determine empirically whether higher or lower entropy correlates with better performance in each batch — a direction-agnostic intervention that adapts to the training stage. This is the same methodological divide as prescriptive vs. adaptive advantage shaping: prescriptive methods (standard entropy bonus, SoftmaxGRPO) impose a direction; adaptive methods (CANON, DASH) infer the direction from data. The pair closes a design space: (prescriptive entropy control) × (adaptive entropy measurement) = two complementary tools for entropy management in LLM RL.
