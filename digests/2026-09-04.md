**VIG adds a sixth axis to the VLM RL design map.** The five axes established through Sep 03: reward signal (StructReward dense process), advantage estimator (MaxPO L2O centering + OTB per-token reweighting), rollout tree efficiency (HARTS prefix sharing), environment model (WM-R1 world-model-embedded thinking), rollout diversity (NC-GRPO latent Gaussian noise). VIG adds a sixth: grounding density reward — scoring each reasoning token by how much the visual input reduces its predictive uncertainty. VIG's reward is computed at the token level (like OTB's gradient weights) but applied to the reward signal side (like StructReward's dense process rewards), creating a new cross-axis: token-level reward signal derived from visual information content.

**Agon restructures the reward source from static annotation to dynamic rival capacity.** The entire Sep GRPO improvement stack (MaxPO, OTB, StructReward, NC-GRPO, VIG) optimizes the policy given a fixed reward signal. Agon replaces the reward signal itself: rather than a trained reward model or verifiable outcome, reward is whether you out-solve a rival of comparable strength that has seen your work. The self-improving dynamic (stronger rival → harder task → stronger model) is structurally similar to RLAIF/Constitutional AI but avoids the distributional collapse risk of self-training from the same model's outputs. Agon pairs naturally with Demystifying RL Post-Training's finding that RL success requires base model prior probability on correct behaviors: as Agon's rival strengthens, the correct solution space shifts, providing curriculum-like pressure without explicit curriculum design.

**CTA extends the faithfulness audit from reasoning-trace level (CSR/FACE-Eval/REDAgentBench) to skill-attribution level.** Prior papers in this thread targeted one of three failure modes: covert adoption of tool returns without verbalization (FACE-Eval), verbalized constraints violated in execution (REDAgentBench), and intermediate steps not causally necessary for correct outputs (CSR). CTA reveals a fourth failure mode: skill attachment itself is behaviorally opaque to pass-rate metrics — 522 behavioral changes detected vs. +0.3 pp aggregate pass-rate change. The four papers together constitute a complete audit framework for agent faithfulness: CTA (skill-level attribution), FACE-Eval (CoT-tool-return faithfulness), REDAgentBench (verbalization-execution faithfulness), CSR (causal step-necessity). No paper studies all four failure modes jointly or proposes a unified training intervention.

**GAP adds a task-dependency-structure axis to agentic RL systems.** HARTS controls compute efficiency (prefix sharing in rollout trees); TeamTR controls policy staleness (trust-region resampling in multi-agent fine-tuning); GAP controls execution structure (dependency-graph-based parallelization of independent tool calls). The three papers address orthogonal axes of the same problem: making large-scale agentic RL with tool use computationally tractable. No paper combines graph-based dependency modeling (GAP) with prefix-sharing efficiency (HARTS).

**LLM-jury provides a theoretical floor for when Agon's rival-grading can substitute for trained reward models.** The shared-error floor (near zero on math/code, non-trivial on science/open-ended domains) explains why verifiable-reward RL (GRPO on math/code) works well with outcome rewards — the jury's error floor is low, so both Agon's rival grading and standard outcome-based GRPO encounter few ambiguous cases. For open-ended VLM tasks where the error floor is higher, LLM-jury suggests using larger panels (more diverse models) to push the floor down rather than training a domain-specific reward model.
