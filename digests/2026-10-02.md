## Open gaps (updated)

**Step-credit cluster now five entries**: ASCT (inference-time action tree, RAG) + TEMPO (training-time prefix tree) + SIPO (order-statistic correction for selection bias) + DARS (predicate-DAG with distilled annotator) + T2SPO (regression from past trajectories) + TASPO (PI-weighted mean-preserving advantage). TASPO's supervision-credit gap formalization is the conceptual anchor for the whole cluster: all five designs are essentially different answers to the question "given a verified outcome, how should credit be redistributed across steps?"

**No-gold-labels reward cluster now four entries**: CCS (cycle-consistency, output-side) + cross-attention RL (attention fidelity, input-side) + TGPO PRM (subgoal progress, action-side) + RFPO (frozen critic posterior, trajectory-side). RFPO raises an internal consistency question: if the frozen critic was trained with verifiable rewards, does RFPO "cheat" by requiring labels at critic training time? The method's claim of being "reward-free" depends on whether the critic itself required annotated data.

**HDL + SIPO composability**: HDL selects where to branch (high hindsight-divergence positions); SIPO corrects how to estimate branch values (order-statistic debiasing). These appear compositional — run HDL to identify branch points, then apply SIPO's correction to the resulting tree. No paper combines both yet.
