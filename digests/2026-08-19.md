**GUPO closes the gradient-conflict gap in GRPO's aggregation step.** The vault's GRPO training papers (SRGPO, Temporal GRPO, PASS@(k,T), GRPO Beyond English) have all treated the group-gradient aggregation step as fixed: gradients are averaged uniformly across queries in a mini-batch. GUPO shows empirically that group-gradient conflicts — queries pulling in conflicting update directions — are correlated with less effective policy updates, and fixes this with a Bayesian-Dirichlet uncertainty model that down-weights conflicting gradients. This is a different axis of GRPO improvement than the process reward papers (which address what signal to optimize) or the variance papers (which address variance across rollouts): GUPO addresses the aggregation step itself.

**"Rethinking Generalization in Reasoning SFT" provides the SFT-side complement to the Atomic Skills Prerequisite paper (Aug 17).** The Atomic Skills Prerequisite paper (Aug 17) established that RL synthesis requires pre-mastered atomic skills; this paper establishes the parallel condition for SFT: cross-domain generalization requires sufficient model capability and high-quality verified-CoT data. Together they form a two-sided boundary condition for the SFT→RL curriculum: SFT must use a sufficiently capable model with verified data to internalize transferable procedural patterns; then RL can synthesize novel compositions. The dip-and-recovery pattern is operationally important: checkpoint selection based on early training (before recovery) systematically underestimates SFT generalization. The safety-reasoning asymmetry is a separate, critical finding: SFT generalizes reasoning but degrades safety — a cost that the Atomic Skills framework doesn't account for.

**UMA instantiates the Memory + RL training signal thread's target use case.** The Aug 18 search found the memory thread dominated by retrieval/storage papers rather than papers using memory as an RL training signal. UMA is exactly the target: the RL policy must learn what to write, update, delete, and reorganize in the Memory Bank in order to correctly answer questions downstream — memory operations are trained end-to-end by RL reward, not handcrafted. The Ledger-QA benchmark is particularly useful: it tests whether the accumulated memory state (not the raw context) contains the correct answer, which is the evaluation format the Aug 18 search explicitly described as missing from prior memory papers.

**On-Policy Distillation's "illusory distillation" finding creates a calibration concern for the VLA distillation papers in the vault.** The vault's VLM training papers (BCSD, NoPD, FP-OPD, OGLS-SD — Aug 14-15) and the Explicit Language Memory paper (Aug 18) all rely on distillation-style training to preserve VLM backbone quality. This paper shows that OPD gains in standard reasoning benchmarks can be entirely attributable to sampling efficiency (avg@K), not genuine capability expansion (pass@K). This means: (1) any VLA paper reporting improved average task success under distillation may be measuring sampling efficiency, not capability transfer; (2) the correct diagnostic is to run the pre- and post-distillation model at large K and compare pass@K — if the base model matches or exceeds the distilled model at high K, the distillation is illusory for that domain.

**GRPO Beyond English reveals that multilingual RLVR carries asymmetric regression risk.** The vault's GRPO papers assumed English training. This paper shows native-language training nearly matches English performance and transfers crosslingually — but that crosslingual transfer is asymmetric: some source languages improve others, some cause regressions. The implication for any multilingual agentic RL system using GRPO is that single-language training may unknowingly degrade performance on other languages, and this can only be detected with broad multilingual evaluation.
