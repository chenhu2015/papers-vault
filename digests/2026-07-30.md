**New thread — IG-based multi-turn credit assignment lineage now fully characterized:** IGPO (Oct 2025, P(correct answer) per turn) → InfoReasoner (Jan 2026, semantic clustering uncertainty reduction, theoretically grounded) → InfoPO (Feb 2026, counterfactual action-distribution IG + variance-gated fusion) → CIGPO (Jul 2026, reference log-likelihood IG, turn-level decomposition of Progress Advantage). The three IG definitions now form a taxonomy: (1) log-likelihood-based (IGPO/CIGPO), (2) semantic-clustering-based (InfoReasoner), (3) counterfactual-distribution-based (InfoPO). Each is model-agnostic in a different sense: IGPO/CIGPO require a reference model; InfoReasoner requires only forward passes with semantic comparison; InfoPO requires only paired masked/unmasked forward passes. InfoReasoner's telescoping additivity proof retroactively provides the formal guarantee that CIGPO's per-turn decomposition of Progress Advantage is well-defined.

**Gap #16 updated — TAO-RL provides the first tool-use angle group-filtering fix:** TAO-RL's trajectory filtering (remove all-correct and all-incorrect groups) is the clearest direct implementation of group-level filtering for Gap #16's degenerate advantage pathology. It is the first paper in the vault that explicitly removes both types of degenerate groups rather than fixing the reward signal within them. Gap #16 fix landscape now: Dark Room (variance-profile criterion), RDPO (quantile normalization), P-GRPO/EmoAgent-R1 (PMI token modulation), CIGPO (IG variance injection), OC-GRPO (IS-corrected guided rollouts), TAO-RL (explicit group filtering). Six distinct approaches now characterized, each addressing a different failure regime or method. No paper yet addresses the mathematical norm of the z-normalization step itself.

**New skill lifecycle synthesis — Bayesian-Agent complements ReSkill:** ReSkill (Jul 29) uses Thompson Sampling for skill version selection within a lifecycle managed by heuristics. Bayesian-Agent uses a categorical Bayesian posterior to govern the lifecycle itself (retire, split, explore). These are complementary at two levels: ReSkill operates inside the lifecycle (which version to use given the current policy distribution); Bayesian-Agent operates at the lifecycle level (what lifecycle state the skill is in). A combined system would use Bayesian-Agent's posterior for lifecycle state transitions and ReSkill's Thompson Sampling for within-state version selection. This connection was not drawn by either paper.

**InfoPO–TAO-RL synthesis — variance gating is a shared mechanism:** InfoPO's adaptive variance-gated fusion (combine IG signal with task outcomes, weighting by variance) and TAO-RL's entropy bonus at post-tool-call tokens (reshape advantage at high-entropy decision points) share a structural pattern: both modulate the strength of an auxiliary signal based on how much informative variance it carries at a given turn/token. The shared abstraction is: *weight the auxiliary credit signal by its per-token/per-turn variance/entropy* — high uncertainty means the signal is more worth attending to. This is the same principle as STAPO's entropy-gated step selection (Jul 26) and O²-CritiCuRL's multi-rollout frequency analysis (Jul 28), suggesting a general class of variance-adaptive auxiliary credit assignment.
