**Temporal GRPO extends the credit assignment taxonomy to VLA action-level robotics.** The vault's credit taxonomy has covered: token-level (ADRS-TVA, PCSD, OCSD, DASH, CSCR, RP-OPSD), step-level (Guided-OPD, FutureBridge-OPD, Gated-BEPO, SOD), trajectory-level (TACO/DAPR, IBPO), path-level (Parallel Shapley), and segment-level (SHAPE, MBPO). Temporal GRPO introduces a new instance of segment-level credit applied to **VLA action sequences** rather than language token sequences: task stages define the segments, and rollout comparison is restricted to rollouts at the same stage. This is structurally analogous to MBPO's branch-relative segment advantages (segments defined by VL decision boundaries) but for action-level VLA policies where stages are defined by observable task structure. The trajectory-level credit aliasing problem (correct early-stage actions penalized by trajectory-level failure) is a direct analog of SHAPE's motivation (segments with different solvability get uniform advantage) — Temporal GRPO solves the VLA version of the same aliasing problem.

**FP-OPD introduces capacity-aware projection as a new OPD mechanism dimension.** The vault's OPD mechanism taxonomy has focused on: *which tokens* receive supervision (RP-OPSD, DASH, SSOPD, CSCR), *when* supervision is applied (SOD's divergence-adaptive gating, SSOPD's frontier weight), *what supervision source* to use (Guided-OPD: state selection, FutureBridge-OPD: future trajectory validation, SSOPD: intra-group contrast, BCSD: bidirectional context contrast). FP-OPD introduces a fourth dimension: *which direction* of teacher correction is realizable by the student. The Fisher-metric projection is a capacity-aware filter that discards teacher signal in directions the student cannot represent — a principled solution to the OPD capacity mismatch that DASH's threshold and SSOPD's frontier weight address heuristically.

**NOPD and SSOPD together define the space of external-teacher-free supervision.** SSOPD (Aug 13) uses within-rollout-group outcome contrast (correct vs. wrong completions) as dense process supervision without external teachers. NOPD uses within-sample input corruption contrast (clean vs. noisy predictions) as self-supervision without external models. These are the two principal axes of external-teacher-free supervision: (1) outcome-conditioned trajectory contrast (SSOPD), (2) input-conditioned observation contrast (NOPD). A natural extension would combine both: use NOPD-style input corruption within the SSOPD rollout group structure to get supervision that is both outcome-aware and input-perturbation robust. This combination has not appeared in the vault.

**BCSD connects to Gap #21 via the skill utilization supervision angle.** Gap #21 (complexity threshold for skill management) has been framed as: when does a skill set become too complex for the agent to manage, and how should RL training respond? BCSD approaches this from the supervision side: if task-level rewards don't signal skill utilization quality, what signal can? The bidirectional context contrast (augmented Meta-Skill vs. reduced task-specific) is a skill-relevance signal that scales with skill complexity — more complex skill sets create larger divergence between augmented and reduced views. This is a partial empirical proxy for the complexity threshold, not a formal definition, but it is the closest paper to Gap #21 in the vault.

**VERDICT formalizes disagreement-as-signal for step-level verification.** The verifiable process supervision thread (VPS, VPRM, RLVR-incentivizes-reasoning from Aug 11) has focused on defining what constitutes a verifiable intermediate step and how to assign credit. VERDICT addresses the downstream aggregation problem: when multiple verifiers provide step-level scores and disagree, the disagreement structure is informative. The coordination game formulation with a unique closed-form equilibrium makes this computationally tractable without iterative optimization. This is directly relevant to the vault's process reward model thread as a training-free inference-time complement to learned verifiers.
