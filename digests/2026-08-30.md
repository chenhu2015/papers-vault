**EFCA (today's 2nd paper) completes the credit assignment vault taxonomy with a 5th approach.** The taxonomy now covers: (1) SPA-RL — trained progress estimator; (2) MileGPO — template-based PCC milestones; (3) DataPRM/ToolPRM — environment-aware process reward model; (4) IAPO — typed influence-dependency graph from rollout; (5) EFCA — multi-timescale environment feedback with return reweighting, no separate estimator. EFCA's "no external structure beyond observations" position is the most minimalist of the five — it asks what can be extracted from the interaction history before any learned components.

**The OPD/RLVR integration problem now has two distinct solutions in the vault.** AToD (Aug 29) uses a temporal annealing schedule to transition from teacher distillation to RL over training, treating the transition timing as the primary design variable. OPDVR (today) uses per-trajectory ReLU gating to apply both signals simultaneously, requiring no schedule hyperparameter. Both address the same failure modes (OPD bounded by teacher, RLVR too sparse) but with opposite inductive biases: AToD assumes the relative value of each signal changes over training; OPDVR assumes it changes per-trajectory. Neither paper cites the other despite solving the same problem — independent convergence, empirical comparison open.

**SPT opens a pre-training axis in the skill-evolution design space.** All prior skill papers (SkillForge, Skill-R1, Skill1, SKILL0) use skills at RL training time in explicit libraries. SPT shows that absorbing skill packages into base model parameters via mid-training CLM before RL begins outperforms trajectory mid-training. This creates a three-position axis: (a) inference-time retrieval (SKILL0), (b) RL-time library evolution (SkillForge/Skill-R1/Skill1), (c) pre-training absorption (SPT). Whether (b) and (c) are substitutes or complements — whether SPT-initialized models benefit more from SkillForge-style RL — is an open empirical gap.

**Hints/Critics/Teachers is the first vault paper to expose an evaluation artifact in VLM-RL benchmarking.** The finding that one standard in-domain slice anti-correlates with cross-domain transfer (rho=-0.74) while the hardest in-domain slice predicts it (rho=+0.89) is an actionable warning for several recent vault papers using overlapping benchmarks. The HL-Gauss vs. MSE critic finding adds a concrete action item to the reward-model-for-RL design thread: always prefer categorical distributional loss for critic training.
